# 🌤️ AeroWeather

AeroWeather is a sleek and responsive weather forecasting application that allows users to search for any city and view detailed **live weather information** through a clean and user-friendly interface.

## ✨ Features

* 🌍 **City Search** — Search and view weather information for any city.
* 🌡️ **Temperature & Conditions** — View current temperature and weather conditions.
* 💧 **Humidity** — Display current humidity levels.
* 💨 **Wind Speed** — View real-time wind information.
* 🌡️ **Atmospheric Pressure** — Display current pressure data.
* 👁️ **Visibility** — View current visibility conditions.
* 🌅 **Sunrise & Sunset** — Display sunrise and sunset times.
* 🕘 **Recent Searches** — Save recently searched cities for quick access.
* 📱 **Responsive Design** — Optimized for desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

* **React.js**
* **JavaScript**
* **Tailwind CSS**
* **REST API**
* **Git & GitHub**

## 🚀 Getting Started

### Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd AeroWeather
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```
